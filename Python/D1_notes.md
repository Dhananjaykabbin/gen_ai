DAY 1 — PYTHON

Python:
Python is a high-level, general-purpose programming language.

Variable:
A variable is a name that refers to a value.

Basic data types:
str  → text
int  → whole numbers
float → decimal numbers
bool → True/False

input():
Used to receive user input.
Input is returned as a string by default.

type():
Used to identify the type of an object.

Type conversion:
int()
float()
str()
bool()
