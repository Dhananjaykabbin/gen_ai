# Python Interview Notes

## 1. Variables

A variable is a name used to refer to a value/object in Python.

Example:
name = "Dhananjay"

## 2. Dynamic Typing

Python is dynamically typed, so variables do not require explicit type declarations.

Example:
age = 22
name = "Dhananjay"

## 3. input()

input() is a built-in Python function that reads user input and returns it as a string.

Example:
name = input("Enter your name: ")

## 4. Functions

A function is a reusable block of code designed to perform a particular task.

Examples:
print()
input()
type()

## 5. f-string

An f-string is a formatted string literal that allows expressions to be embedded inside a string.

Example:
name = "Dhananjay"
message = f"Hello {name}"
